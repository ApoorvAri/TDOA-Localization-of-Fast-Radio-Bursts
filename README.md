# TDOA-Localization-of-Fast-Radio-Bursts 
Authors: Aric Apoorv Tirkey and Mishthi Sharma under the guidance of Prof. Mohit Bharadwaj (Assistant Professor, SPASE, IIT Kanpur)

Description: Simulation framework for localization of Fast Radio Bursts (FRBs) using the Time Difference of Arrival (TDOA) technique across multiple radio telescopes. The project models geometric time delays between antennas, adds realistic Gaussian timing noise, and estimates FRB source regions through χ² minimization over altitude–azimuth grids. It includes two-antenna ring localization, three-antenna compact localization patches, uncertainty contour mapping, and sky-wide localization analysis using HEALPix/healpy pixelization. The implementation is built in Python using NumPy, Matplotlib, and Healpy for numerical computation, visualization, and localization area estimation.
